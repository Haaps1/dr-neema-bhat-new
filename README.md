# Dr. Neema Bhat, Website

Website for Dr. Neema Bhat, Hematologist, Pediatric Oncologist and Bone Marrow Transplant specialist, Bangalore.

Everything is generated by **`build.py`**. Edit it, then run:

```
python3 build.py
```

This writes two copies of the site:

| Copy | Where | Used for |
|---|---|---|
| Static HTML preview | `*.html` in this folder | GitHub Pages preview |
| **Hostinger site (PHP)** | `hostinger/` (and `hostinger.zip`, not committed) | The live website |

## Uploading to Hostinger

1. In hPanel open **Files → File Manager → public_html**.
2. Upload `hostinger.zip` and choose **Extract**. Make sure the files sit directly in `public_html`
   (you should see `index.php`, `.htaccess`, `includes/`, `assets/`). Show hidden files to see `.htaccess`.
3. In hPanel turn on **SSL** for the domain (the site always redirects to `https://` without `www`).
4. In Google Search Console, add the site and submit `https://drneemabhat.com/sitemap.xml`.

### Coming Soon page: on / off

Open `includes/config.php` and change one line:

```php
define('COMING_SOON', true);   // ON: visitors see the Coming Soon page
define('COMING_SOON', false);  // OFF: the website is live
```

While it is ON you can still see the real site by opening `https://drneemabhat.com/?preview=neema2026`
once (change the word in `PREVIEW_KEY`). The Coming Soon page is sent with a "temporarily unavailable" (503)
status so Google does not drop the site.

### What is in the Hostinger copy

| File | Purpose |
|---|---|
| `includes/head.php` | Shared `<head>`: paste global tags (Google Analytics, GTM, Search Console, Meta Pixel) in the GLOBAL TAGS box and site-wide schema in the GLOBAL SCHEMA box |
| `includes/header.php` | Header and menu, shared by every page (BODY TAGS box at the top for GTM `<noscript>`) |
| `includes/footer.php` | Footer, shared by every page |
| `includes/config.php` | Coming Soon switch and site address |
| `.htaccess` | https + no-www redirects, clean addresses (`/about`), old `.html` → new address redirects, your own redirects (section 4), security headers, caching, compression, custom 404 |
| `404.php` | Page not found |
| `coming-soon.php` | Coming Soon page |
| `privacy-policy.php` | Privacy Policy |
| `robots.txt`, `sitemap.xml`, `llms.txt` | Search engines and AI assistants |

Addresses that start with `www.` are redirected (301) to the address without `www` and also carry a
`noindex` header, so they are never indexed. Every page has a canonical link to the non-www address.

## Editing

- **Site address:** `SITE_URL` in `build.py`.
- **Phone / WhatsApp:** `PHONE_*` / `WA` in `build.py` and `CONFIG` in `assets/js/main.js`.
- **Social links (footer):** `SOCIAL` in `build.py`.
- **Treatments and menu:** `SERVICES` in `build.py`.
- **OPD timings:** `SCHEDULE` in `assets/js/main.js` and the notes in `build.py`.
- **Colours & fonts:** `:root` at the top of `assets/css/styles.css`.
